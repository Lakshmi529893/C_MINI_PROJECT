# Student Database Management System

## About the Project
The Student Database Management System is a menu-driven application developed using the C programming language. It helps manage student records efficiently using data structures and file handling.

The project demonstrates modular programming, linked lists, pointers, dynamic memory allocation, and file operations in C.

## Features
- **Add Student:** Add a new student record with roll number, name, and percentage.
- **Delete Student:** Remove a student record using the roll number.
- **Display Students:** Display all stored student records.
- **Modify Student:** Update the details of an existing student.
- **Sort Students:** Sort student records by name or percentage.
- **Save Records:** Save student information to a file.
- **Dynamic Memory Allocation:** Manage student records using dynamically allocated memory.

```bash

```

